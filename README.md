# Generador de placas de calles

Genera y descarga recreaciones de placas de calle reales de 12 ciudades europeas.

Construido con React + [Vite](https://vitejs.dev/).

## Scripts disponibles

### `npm start`

Arranca el servidor de desarrollo en [http://localhost:5173](http://localhost:5173) (recarga en caliente).

### `npm test`

Corre los tests una vez con [Vitest](https://vitest.dev/).

### `npm run build`

Genera el build de producción en la carpeta `build/`.

### `npm run preview`

Sirve localmente el build de producción ya generado, para probarlo antes de desplegar.
